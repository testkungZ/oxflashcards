กติกานี้เปิดให้เฉพาะบัญชีแอดมินอ่านข้อมูลทุกผู้ใช้ได้ โดยยังปกป้องข้อมูลผู้ใช้ทั่วไปไม่ให้ดูข้อมูลของคนอื่น

                

                
            

            
1. เปิด Firebase Console → Firestore Database → Rules

            
2. วาง Rules ด้านล่าง (ระบบใส่อีเมล/UID ของคุณให้แล้วถ้าล็อกอินอยู่) แล้วกด Publish
